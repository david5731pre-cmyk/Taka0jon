টাকা ওজন ক্যালকুলেটর

এই Android Studio প্রজেক্টে বাংলা UI, টাকা থেকে কেজি/গ্রাম এবং কেজি থেকে টাকা হিসাব রয়েছে।
অ্যাপে INTERNET permission নেই; হিসাব অফলাইনে হয়।

APK তৈরি করতে:
1. Android Studio-তে এই ফোল্ডারটি Open করুন।
2. Gradle Sync সম্পন্ন করুন (প্রথমবার প্রয়োজনীয় Gradle/Android SDK ডাউনলোড হতে পারে)।
3. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
4. APK: app/build/outputs/apk/debug/app-debug.apk

প্রয়োজন: Android Studio, JDK 17 এবং Android SDK Platform 35।
